# Personal Portfolio Website

A responsive, static personal portfolio website designed to showcase software engineering projects, technical skills, and background.

## Pages Included

* **`index.html`** – Introduction and main landing page.
* **`skills.html`** – Detailed breakdown of technical skills, languages, and frameworks.
* **`gallery.html`** – Full-width visual showcase of key projects with direct GitHub links.
* **`hobbies.html`** – Personal interests and activities outside of coding.
* **`contact.html`** – Contact details and links to social profiles.

## Built With

* **HTML5** – Structured web content.
* **CSS3 (Inline Styling)** – Lightweight styling using Flexbox for responsive layouts and card designs.
