# Personal Portfolio Website

A clean, responsive, and modern personal portfolio website built with **HTML5** and **CSS3**. This project showcases my background, technical skills, hobbies, contact information, and a curated gallery of software development projects.

## Features

- **Multi-Page Layout**: Includes Home, Skills, Hobbies, Gallery, and Contact Me pages.
- **Custom CSS Design**: Built entirely with external CSS styling (utilizing floats, custom container layouts, and responsive design principles) without inline styling clutter.
- **Project Gallery**: Displays recent software engineering projects with live links to GitHub repositories.
- **Interactive Navigation**: Active page highlighting across the navigation menu.

## Tech Stack

- **Markup**: HTML5
- **Styling**: CSS3 (Flexbox/Float layouts, responsive units, custom color schemes)
- **Version Control**: Git & GitHub
